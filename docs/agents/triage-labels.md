# Label Triage

Skill agen menggunakan 5 peran triage standar. Dokumen ini memetakan peran-peran tersebut ke label nyata yang digunakan pada issue tracker GitHub di repo ini.

| Label di mattpocock/skills | Label di GitHub Tracker | Arti / Makna                              |
| -------------------------- | ----------------------- | ----------------------------------------- |
| `needs-triage`             | `needs-triage`          | Maintainer perlu mengevaluasi isu ini     |
| `needs-info`               | `needs-info`            | Menunggu informasi tambahan dari pelapor  |
| `ready-for-agent`          | `ready-for-agent`       | Spesifikasi lengkap, siap dikerjakan agen |
| `ready-for-human`          | `ready-for-human`       | Butuh implementasi / keputusan manusia    |
| `wontfix`                  | `wontfix`               | Tidak akan dikerjakan                     |

Ketika suatu skill menyebut peran (contoh: "apply the AFK-ready triage label"), gunakan string label yang sesuai dari tabel di atas.

Jika Anda ingin mengubah penamaan label di masa depan, cukup perbarui kolom sebelah kanan agar sesuai dengan label yang digunakan di repo.
